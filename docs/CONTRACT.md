# Engine contract

`src/types.ts` is the shared contract. Pure engine `compareImages(baseline, candidate, options): Comparison` in `src/engine.ts`. Compare a union canvas at top-left without stretching. Dimensions outside either image always count as changed, except ignored areas. Compare overlapping RGBA composited over white with weighted RMS color distance `sqrt((.2126*dr²+.7152*dg²+.0722*db²))/255`; changed iff distance > threshold (0..1). Ignore rectangles use integer half-open pixel coordinates. Group changed pixels in 16px tiles; 8-neighbor connected occupied tiles become one region with bounds of actual changed pixels and exact count. Filter regions below minRegionPixels, but never omit their pixels from total statistics; report omittedRegions/omittedPixels. Region ID coordinate-based `r-x-y-w-h`. Sort descending pixels then y/x. Limits: union <= 12,000,000 pixels; individual side <= 8192px; max 1000 displayed regions, excess in omitted counts. Empty images invalid. Threshold default .08, minimum region 8. No learned model or semantic inference. Engine rejects invalid options and mismatched buffers. Worker runs computation off main thread.

UI review decisions are invalidated when inputs/options/masks change. No image transmission or external runtime assets. Exports intentionally include original images and notes. Python CLI implements same algorithm and uses shared golden fixtures.
